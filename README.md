## Setup (GitHub Pages)

To enable GitHub Pages for this repository:

1. Go to **Settings → Pages**
2. Select **Deploy from a branch**
3. Choose branch **main** with folder **/ (root)**
4. Click **Save**

GitHub will deploy the site within 1-2 minutes.
